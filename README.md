# Todo Artesanal

Sistema de gestión para un emprendimiento de viandas.

Esta rama contiene la nueva reconstrucción de Todo Artesanal, basada en React, Vite, TypeScript, Supabase y PostgreSQL.

## Estado

Proyecto en etapa inicial de reconstrucción arquitectónica.

La documentación completa se actualizará a medida que la arquitectura, el modelo de datos y las funcionalidades queden implementados y verificados.
