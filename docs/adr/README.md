# Architecture Decision Records

Registro de decisiones arquitectónicas relevantes. Cada ADR documenta:

- **Contexto**: qué problema o pregunta motivó la decisión.
- **Decisión**: qué se decidió.
- **Consecuencias**: qué implica, qué se gana, qué se pierde.
- **Alternativas consideradas**: qué se descartó y por qué.
